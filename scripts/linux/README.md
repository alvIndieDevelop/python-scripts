# Utilidades Linux

Herramientas independientes orientadas a Arch Linux y derivados.

| Proyecto | Función | Ejecución |
| --- | --- | --- |
| [Arch Maintenance](arch-maintenance/README.md) | Actualización, limpieza, diagnóstico y recordatorios | `python3 arch-maintenance/arch_maintenance.py --help` |
| [Developer Environment](developer-environment/README.md) | Instalación guiada de herramientas de desarrollo | `sudo python3 developer-environment/developer_environment.py --help` |

Ambos scripts usan la biblioteca estándar de Python, pero requieren comandos y
servicios propios de Arch Linux. Revise sus README antes de ejecutar operaciones con
`sudo`.
